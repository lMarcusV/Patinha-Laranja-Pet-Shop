# Patinha Laranja Pet Shop

A demo online pet shop, created for practicing navigation and manual testing. The interface is in Portuguese and does not require an installation ,or external libraries.

## How to run

1. Open https://lmarcusv.github.io/Patinha-Laranja-Pet-Shop-App/ in a modern browser.
2. Browse the catalog, choose a product, and add it to the cart.
3. In the cart, enter a valid eight-digit Brazilian postal code (CEP) to see a fictional shipping estimate.
4. Continue to checkout, enter fictional delivery details, choose a simulated payment method, and confirm the order.
5. View the order history under **My Orders**.

## Features

- Product catalog with search, categories, sorting, and filters.
- Product details, promotional pricing, availability, and quantity controls.
- Cart with quantity editing, item removal, subtotal, shipping, and total.
- Fictional CEP-based shipping estimates and free shipping on orders over R$250.00.
- Multi-step checkout: delivery, payment, and order review.
- Delivery information and sample inventory validation.
- Simulated order history and order details.
- Local persistence for the cart, inventory, orders, and preferences via `localStorage` (with an in-memory fallback when local storage is unavailable).
- An option to reset the demo data in the browser.
- Responsive layout, keyboard navigation, status messages, and support for reduced-motion preferences.

## Demo limitations

This aplication is not connected to a backend, payment gateway, real shipping service, or delivery system. Prices, inventory, availability, shipping, and delivery times are illustrative. No charges are made and no items are shipped. Use fictional information only at checkout; delivery details are not saved in the browser.

Saved state is specific to the browser used to open the page. Clearing that browser's data or using another browser or profile may remove or hide the existing cart, inventory, and orders.
